Agrupación de Géneros

Implementamos un algoritmo para agrupar géneros frecuentemente asociados, reduciendo la dimensionalidad del problema y mejorando la generalización.

def group_genres(genre_list_str): import ast try: genres = ast.literal_eval(genre_list_str) if not isinstance(genres, list): return [] except: return [] # Eliminar géneros raros genres = [g for g in genres if g not in {'News', 'Short'}] # Definir grupos de géneros genre_groups = { 'Drama-Crime': ['Drama', 'Crime'], 'Romance-Drama': ['Romance', 'Drama'], 'Romance-Comedy': ['Romance', 'Comedy'], 'Thriller-Action': ['Thriller', 'Action'], 'Thriller-Crime': ['Thriller', 'Crime'], 'Thriller-Mystery': ['Thriller', 'Mystery'], 'Adventure-Action': ['Adventure', 'Action'], 'Drama-Action': ['Drama', 'Action'], 'Family-Comedy': ['Family', 'Comedy'], 'Thriller-Horror': ['Thriller', 'Horror'], 'Fantasy-SciFi': ['Fantasy', 'Sci-Fi'], 'Music-Musical': ['Music', 'Musical'], 'History-War': ['History', 'War'] } genres_set = set(genres) result = set() used_genres = set() for group_name, members in genre_groups.items(): if genres_set.intersection(members): result.add(group_name) used_genres.update(members) ungrouped = genres_set - used_genres result.update(ungrouped) top_8 = { 'Documentary', 'Western', 'History-War', 'Sport', 'Animation', 'Film-Noir', 'Thriller-Horror', 'Adventure-Action' } reduced_result = [] for r in result: if r in top_8: reduced_result.append(r) else: reduced_result.append('Other') return list(set(reduced_result))

Visualización del Proceso TF-IDF

El proceso de TF-IDF convierte texto en vectores numéricos, donde cada dimensión corresponde a un término del vocabulario y cada valor refleja la importancia del término en el documento.
