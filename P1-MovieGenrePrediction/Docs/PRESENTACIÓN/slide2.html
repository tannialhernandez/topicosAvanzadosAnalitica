¿Qué problema intentamos resolver?

Buscamos predecir automáticamente el género de una película basándonos únicamente en su sinopsis o plot, utilizando técnicas avanzadas de procesamiento de lenguaje natural (NLP) y aprendizaje automático.

Este desafío implica comprender el lenguaje narrativo, identificar patrones lingüísticos y reconocer elementos temáticos que caracterizan a los diferentes géneros cinematográficos.

Ejemplo de Plot

"En un mundo post-apocalíptico, un solitario sobreviviente debe atravesar un terreno peligroso para encontrar un refugio seguro. En el camino, encuentra a una joven misteriosa que podría ser la clave para salvar a la humanidad."

¿Podrías identificar el género? El sistema debe ser capaz de reconocer elementos como temática, vocabulario, tono y estructura narrativa para clasificar correctamente los géneros predominantes y secundarios.
