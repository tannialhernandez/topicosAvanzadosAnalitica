Enfoque Ensemble Especializado

Estrategia de Modelado por Género

Dado que los enfoques anteriores mostraron limitaciones, especialmente con clases minoritarias, implementamos un enfoque ensemble especializado con modelos independientes para cada género.

  • Modelo por género: Regresión logística independiente para cada uno de los nueve géneros
  • Para géneros minoritarios: Leave-One-Out Cross-Validation para géneros con menos de 400 ejemplos
  • Para géneros mayoritarios: KFold=5 con submuestreo estratégico de ejemplos negativos
  • Balanceo adaptativo: Ponderación de clases y submuestreo controlado según las características de cada género

Modelo Seleccionado y Predicciones

Modelo Final: Ensemble Especializado

Selección Final: Ensemble Especializado de Regresiones Logísticas

Después de evaluar exhaustivamente los modelos, hemos seleccionado el Ensemble Especializado de regresiones logísticas como nuestra solución final. Este enfoque proporciona tanto alta precisión como capacidad de interpretación, ofreciendo probabilidades específicas para cada género y adaptando los umbrales de decisión según la confianza relativa.

Características principales:
  • Arquitectura: Un clasificador de regresión logística independiente para cada género
  • Parámetros optimizados: Configuración específica por género según la distribución de datos
  • Umbral dinámico: Sistema adaptativo basado en media y desviación estándar de las probabilidades

Conclusiones Finales

Tras evaluar exhaustivamente diferentes enfoques para la predicción multi-etiqueta de géneros cinematográficos, hemos extraído las siguientes conclusiones:

  • Superioridad del enfoque especializado: El ensemble de modelos específicos por género superó significativamente a los enfoques de modelo único, demostrando la importancia de adaptar la estrategia de modelado a las características específicas de cada clase.
  • Importancia del balance de clases: Las estrategias de submuestreo y ponderación fueron fundamentales para mejorar la predicción de géneros minoritarios, evidenciando que el desbalance de clases era uno de los principales desafíos del problema.
  • Efectividad de modelos lineales: Los modelos lineales (regresión logística) demostraron ser más efectivos que los modelos basados en árboles para esta tarea, posiblemente debido a la naturaleza dispersa de las características textuales.
  • Umbral dinámico para predicciones: La implementación de un umbral dinámico basado en estadísticas de las probabilidades permite adaptar las predicciones a la confianza específica del modelo para cada muestra.
  • Compromiso entre generalización y especificidad: El enfoque ensemble logró un buen balance entre generalización (AUC promedio en test de 0.8955) y capacidad predictiva para géneros específicos (F1-Scores superiores a 0.64 para todos los géneros).
